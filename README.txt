大学過去問合否シミュレーター（データ分離版）

ファイル構成
- index.html : UIと共通計算エンジン
- admissions-data.js : 実際に計算へ使う年度×募集単位データ
- university-config.js : 大学ごとの過去問素点満点などUI設定
